# Release notes — 0.2.0 "Distributable & deploy-verified"

> **Status: draft** — pending the 0.2.0 gates (CI green, `v0.2.0` image push with digests, `kind`
> smoke transcript, `terraform plan`). Placeholders below (`<digest>`, transcript) are filled at cut
> time. Plan: [docs/release-plan-0.2.0.md](../release-plan-0.2.0.md).

0.1.0 proved the scaffold **builds and passes its own gates**. 0.2.0 turns it into a **distributable
artifact**: reproducible toolchain, signed/attested container images, an in-cluster smoke on `kind`,
MSK hardening, and the first Phase-2 surface.

## Highlights

- **Reproducible toolchain** — committed Gradle **8.12.1** wrapper (`gradlew`, `gradlew.bat`, wrapper
  jar with pinned `distributionSha256Sum`) + repo-level `gradle.properties`; CI now drives the wrapper.
- **Container images** — eight services built and published to `ghcr.io/logistics-os/<svc>:0.2.0`
  via `.github/workflows/images.yml` (`ops/containers/service.Dockerfile`), each embedding the
  OpenTelemetry java agent and carrying **OCI provenance + SBOM** attestations.
- **`kind` smoke** — `ops/kind/smoke.sh` rehearses `kubectl apply -k ops/k8s` with an in-cluster
  `legacy-simulator → acl-tms → canonical → read-model` E2E plus OTel collector trace check; wired
  into CI via `.github/workflows/smoke.yml` (**manual + nightly**, builds/loads images locally).
- **MSK / Terraform hardening** — parameterized client auth (SASL SCRAM/IAM + TLS), per-cluster
  Streams replication factor, lockfile/destroy hygiene, documented Schema-Registry switch.
- **Phase-2 surface** — `core:phase2-stubs:orchestrator` (boots, emits `orch.command.v1`, unit +
  embedded-Kafka IT); `wms.v1.*` payloads promoted `scaffold → canonical` with mapper coverage.
- **Sellable editions (preview)** — SKU catalog [`editions/`](../../editions/README.md) and commercial
  docs [`docs/product/`](../product/editions.md); a framework-agnostic [`platform:entitlement`](../../platform/entitlement/README.md)
  seam wired into `control-tower` (`GET /tower/entitlement`, **soft/permissive** for now); per-customer
  k8s overlays [`ops/k8s/overlays/{dhl,fedex}`](../../ops/k8s/overlays/README.md) set namespace, image
  tag, branding, and a license.
- **Release automation** — [`.github/workflows/release.yml`](../../.github/workflows/release.yml) builds
  one **edition's** service subset (schema-validated catalog), pushes to GHCR, and **cosign**-signs by
  digest; a base run publishes the GitHub release.

## Deploy

```bash
# in-cluster rehearsal (throwaway cluster)
ops/kind/smoke.sh
# base deployment on a real cluster
kubectl apply -k ops/k8s
# per-customer deployment (namespace + tag + branding + license)
kubectl apply -k ops/k8s/overlays/dhl
```

See [docs/engineering-build.md](../engineering-build.md) §6, [ops/k8s/README.md](../../ops/k8s/README.md),
and [ops/k8s/overlays/README.md](../../ops/k8s/overlays/README.md).

## Contracts

- `wms.v1.WmsTaskEvent` and `wms.v1.InventoryMove` promoted `scaffold → canonical` in
  `contracts/payload-registry.json`; mapper now covers `inventoryRef` / `referenceRef`; baselines
  re-snapshotted. `obs.v1.*` remain `scaffold`, `orchestration.v1.*` remain `draft`.

## MSK / Terraform

- `client_auth_sasl_scram|iam|tls` variables (default off) wired into `main.tf`; SCRAM and IAM are
  mutually exclusive.
- `read-model-builder` reads `STREAMS_REPLICATION_FACTOR` (default `1`; raise for MSK).
- Schema Registry not deployed yet — clients run `schema.resource=true`. See
  [ops/terraform/README.md](../../ops/terraform/README.md) → "MSK hardening (M4)".

## Known limitations

- Single-replica services (no HA); read-model-builder stream state uses `emptyDir`.
- OTel collector uses the `debug` exporter (no backend); no ingress/HPA/PDB.
- `kind` smoke is wired into CI (`smoke.yml`, manual + nightly) but has not yet had a green run.
- Edition entitlement is **soft** (permissive) enforcement; signed-license verification, tenant
  binding, and limit enforcement are the "hard" follow-up ([licensing.md](../product/licensing.md)).
- Edition service subsets are respected by `release.yml` (build) and the overlay `resources`; catalog
  linting/`editions/schema.json` validation is manual / in `release.yml` only.
- No live image push / `terraform apply` has been executed as part of authoring this draft.

## Upgrade / rollback

- Images are immutable per digest; roll back manifests to `:0.1.0` if needed.
- Source rollback = revert the release commit/tag. No data migrations in this release.
